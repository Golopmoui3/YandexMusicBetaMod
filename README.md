# 🎵 Яндекс Музыка — мод без Плюса

Набор модов для десктопного приложения Яндекс Музыка, позволяющих пользоваться программой без подписки, скачивать треки и многое другое.

![cover](https://github.com/user-attachments/assets/be3a2e17-e7ef-4493-b42f-1dc97682e114)

> [!NOTE]
> Это **форк** репозитория [Stephanzion/YandexMusicBetaMod](https://github.com/Stephanzion/YandexMusicBetaMod).
> Вся оригинальная работа принадлежит [@Stephanzion](https://github.com/Stephanzion).
> Этот форк содержит исправления багов и небольшие улучшения качества кода — см. секцию [Изменения в форке](#-изменения-в-форке) ниже.

> [!WARNING]
> Яндекс начал вешать плашку "Уязвимость в приложении" или "Промокод Upgrade" и вставлять рекламу в треки для некоторых аккаунтов, которые пользуются обходами плюса. Эта проблема решается модом.
> Но к сожалению, некоторым аккаунтам Яндекс полностью отключает "мою волну", это пофиксить уже невозможно, только создавать новый аккаунт.
>
> Тексты песен временно не работают, это ограничение Яндекса.

## 💀 Ограничения

- У Яндекса строгие региональные ограничения — приложение работает только в [некоторых странах](https://yandex.ru/support/music/ru/access.html). Если вы используете VPN — поменяйте геолокацию на одну из них.
- Не работают подкасты и тексты песен. Работа над этим ведётся.

## 💻 Установка

1. Скачайте последний релиз из вкладки [Releases](../../releases/latest).
2. Запустите установщик.
3. Готово! Мод можно использовать параллельно с обычной Яндекс Музыкой.

## 🔧 Изменения в форке

По сравнению с [оригинальным репозиторием](https://github.com/Stephanzion/YandexMusicBetaMod):

### 🐛 Исправлены баги

| # | Файл | Проблема | Что сделано |
|---|------|----------|-------------|
| 1 | `src/mod/main.js` | `openDownloadDirectory`: `await` в не-async функции + `ReferenceError: customDownloadPath` | Обработчик сделан `async`, убрана ссылка на несуществующую переменную |
| 2 | `src/mod/main.js` | `electron.openPath` — такого метода нет, должно быть `electron.shell.openPath` | Исправлено в двух местах (`openFolder`, `openDownloadDirectory`) |
| 3 | `src/patcher/patcher.ts` | `if (appAsarPath)` — `path.resolve` всегда возвращает непустую строку, проверка фейковая | Заменено на `fs.existsSync(appAsarPath)` |
| 4 | `src/mod/features/utils/utils.js` | Пустой `try/catch {}` глушит сетевые ошибки в `fetch` | Убран бесполезный try/catch — ошибки теперь пробрасываются нормально |
| 5 | `src/patcher/index.ts` | Мёртвый импорт `downloadBuild` | Удалён |
| 6 | `scripts/debug-copy-ui.js`, `scripts/debug-prettier.js` | Захардкоженные (и разные) версии Яндекс Музыки | Скрипты теперь автоматически берут самую свежую версию из `.versions/` |

Все фиксы аккуратно изолированы и не меняют поведение в случае работающих сценариев — только исправляют сломанные.

### ⚡ Улучшения Discord RPC (v2.9.1)

- **Больше не мигает присутствие.** Пока плеер не может отдать состояние (навигация, перерисовка, старт трека), 30 секунд отдаётся последнее валидное состояние вместо сброса RPC.
- **Быстрее находится причина поломок.** В Sentry теперь уходят настоящие `Error` со стеком (раньше — строки), один и тот же контекст — не чаще раза в 5 минут, чтобы не сжигать квоту проекта.
- **Чистая консоль.** Если окно приложения закрыто, main-процесс больше не сыпет ошибкой каждые 500 мс.

### 🤖 Автосборка релизов (v2.9.1)

Workflow `.github/workflows/release.yml`: на каждый тег `v*` (или вручную через workflow_dispatch) на GitHub Actions поднимается `windows-latest`, выполняется полный пайплайн (`bun start` — скачивание, патч, сборка), а готовый установщик + SHA256-чекуммы автоматически прикладываются к релизу. Сборка больше не требует локальной машины.

### ⚙️ Добавлен workaround для сборки на Windows без админских прав

`electron-builder` падает на распаковке `winCodeSign-2.6.0.7z` без прав администратора или включённого Developer Mode — в архиве лежат darwin symlink-файлы, которые Windows не даёт создавать обычному пользователю. Добавлен `src/patcher/wincodesign-workaround.ts` — обёртка над `7za.exe`, исключающая проблемные файлы (для Windows-сборки они не нужны). Применяется автоматически при `bun start`. См. `scripts/7za-wrapper.ts` и `CLAUDE.md` для деталей.

## 🏗️ Сборка из исходников

```bash
# 1. Установите Bun: https://bun.sh
bun --version

# 2. Установите зависимости
bun install

# 3. Полная сборка (скачает оригинальную Яндекс Музыку, запатчит, соберёт установщик)
bun start
```

Полный pipeline патчера описан в [`MODDING_GUIDE.md`](./MODDING_GUIDE.md) и [`CLAUDE.md`](./CLAUDE.md).
